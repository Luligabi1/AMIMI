**AMIMI (Advanced Multiblock Info for Modern Industrialization)** is an adaptation/port of [GregTech CEu](https://modrinth.com/mod/gregtechceu-modern)'s multiblock viewer, fully replacing MI's.

![A 3D preview of a Distillation Tower inside a recipe viewer](https://cdn.modrinth.com/data/cached_images/1b6be69d2a6a6acfffb3ff8ef365e4ed92afe867.png)

![A 3D preview of a multiblock. A specific block is hovered, highlighting it can be replaced by energy output hatches.](https://cdn.modrinth.com/data/cached_images/bf15ca929f40d3f323326ca5e346b660c2594df8.png)


# Features

- Full 3D view of all multiblocks within your recipe viewer
- See multiblocks layer by layer
- Open GuideME page, if available
